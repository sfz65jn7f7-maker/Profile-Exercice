# TP 1 — Programmation mobile

Exercice d’initiation avec **Vite**, **React (JSX)** et **Tailwind CSS**.

## Notions travaillées

- Afficher des profils sous forme de stories Instagram.
- Récupérer les profils au format JSON depuis une API.
- Créer des compteurs indépendants avec `+` et `−`.
- Limiter les compteurs entre `0` et `20` avec l’opérateur ternaire.
- Changer leur couleur selon leur valeur : rouge, orange ou vert.
- Ajouter un titre et un cadre au format mobile.
- Installer et utiliser Tailwind CSS localement.

## Lancer le TP

```bash
npm install
npm run dev
```
